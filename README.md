GA-SDK-ANDROID
==========

GameAnalytics native Android SDK.

Documentation can be found [here](https://gameanalytics.com/docs/android-sdk).

If you have any issues or feedback regarding the SDK, please contact our friendly support team [here](https://gameanalytics.com/contact).

> :information_source:
> Requirements:
> **Android:** Lollipop 5.0 (API level 21) and up
>
> **Build size:**
> Note that download size differs from the actual build size. The SDK build size is only around **190Kb** plus its single dependency (`play-services-appset`) if your app does not already include it.

Repository contents
---------
* `GA/aar` — the SDK as an Android library (`gameanalytics.aar`)
* `GA/jar` — the SDK as a plain jar
* `GA/cpp` — C++ wrapper sources for native integrations
